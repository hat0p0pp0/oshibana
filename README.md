# オシバナ（モック）

自分の考え方の「型」を知り、伸ばしたい方向の講師と、同じテーマを推す仲間と学び直すプラットフォームのモックです。
スマホでもPCでも動き、スマホではホーム画面に追加してアプリのように使えます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・デザイン・ダミーデータ・動作をすべて含む） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・色の設定 |
| `sw.js` | オフラインでも開けるようにする仕組み（Service Worker） |
| `icons/` | アプリのアイコン画像 |
| `README.md` | この説明書 |

ビルド（変換作業）は不要です。ファイルを置くだけで動きます。

## GitHub Pagesで公開する手順

### 1. リポジトリを作る
1. GitHubにログインし、右上の「＋」から「New repository」を選びます
2. Repository name に `oshibana` と入力します
3. 公開範囲は **Public** を選びます（無料プランでGitHub Pagesを使うにはPublicが必要です）
4. 「Create repository」を押します

### 2. ファイルをアップロードする
1. 作成したリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）を押します
2. このフォルダの中身（`index.html`、`manifest.webmanifest`、`sw.js`、`README.md`、`icons` フォルダ）をまとめてドラッグ＆ドロップします
3. 下の「Commit changes」を押します

### 3. 公開を有効にする
1. リポジトリの「Settings」→ 左メニューの「Pages」を開きます
2. 「Build and deployment」の Source で「Deploy from a branch」を選びます
3. Branch で `main`、フォルダで `/ (root)` を選び、「Save」を押します
4. 数分待つと、画面上部に公開URLが表示されます
   `https://（あなたのGitHubユーザー名）.github.io/oshibana/`

### 4. スマホのホーム画面に追加する
- **iPhone**：Safariで公開URLを開き、共有ボタン →「ホーム画面に追加」
- **Android**：Chromeで公開URLを開き、メニュー →「アプリをインストール」または「ホーム画面に追加」

## 更新のしかた
1. リポジトリのトップ画面で「Add file」→「Upload files」を開きます
2. `index.html`・`sw.js`・`manifest.webmanifest`・`README.md`・`icons` フォルダを**リポジトリの一番上の階層に**ドラッグします（同じ名前のファイルは上書きされます）
3. 「Commit changes」を押します
4. リポジトリの「Actions」タブで、緑のチェック（pages build and deployment）が付くまで1〜3分待ちます
5. 公開URLを開き、マイページの一番下（または最初の画面の一番下）に表示される**バージョン**が新しくなっていることを確認します

### 古い画面のままのとき
- リポジトリのトップに `index.html` が直接並んでいるか確認してください。`oshibana` フォルダの中に入っていると、公開URLには反映されません
- PCのブラウザは Ctrl＋Shift＋R（Macは Cmd＋Shift＋R）で再読み込みします
- スマホのホーム画面アプリは、一度アプリを完全に閉じてから開き直すか、Safari／Chromeで公開URLを直接開いて再読み込みします

## 使い方

### ユーザー
- 最初の画面から「無料で新規登録」→ ニックネーム・年齢（18歳以上）を入力 → 診断へ進みます
- 診断後は、ホーム・診断結果・推しコミュ・イベント・マイページを使います

### 管理者
- 最初の画面の「管理者の方はこちら」、またはマイページの「データの管理」→「管理者ログイン」から入ります
- モック用のパスコードは `admin` です（ブラウザ内だけの簡易的な制限です）
- 管理者の画面でできること
  - **概要**：合成データの集計（分布・人気テーマ・継続率など）
  - **ユーザー**：合成ユーザー300人の一覧と詳細、画面確認用ユーザーとして実際の画面を操作
  - **講師**：講師の画面（投票の承認、イベント提案、手数料、受け取ったエール）
  - **イベント**：過去の会120件と現在の会の一覧
  - **データ**：機械学習用のCSV（users / participations / events / lecturers / themes）とJSONの出力

### 機械学習用の合成データ
- 乱数シード `20260927` で生成するため、毎回まったく同じデータになります
- ユーザー300人、過去のイベント120件、参加記録約750件、講師36人、テーマ36件
- `retained_90d`（90日後の継続）や `rating_to_lecturer`（講師への評価）などは、予測の練習ができるように、もっともらしい関係を持たせて作った架空の値です

## RPGの仕組み
- **職業**：診断で「いまの職業」と「転職先（アンラーンして目指す職業）」「上級職」が決まります（6軸×西洋・東洋の12職業＋上級職6）
- **必殺ワザ**：推しテーマが必殺ワザになり、投稿やイベント参加でワザのレベルが上がります
- **レベル**：診断・投稿・エール・参加表明・イベント参加などで経験値がたまります
- **装備**：拠点（ホーム）のアバターを着せ替えできます。装備はすべてエールで購入し、「参加パス付き装備」を買うと学びの会の参加枠がセットで手に入ります（参加費は別途）。会に参加すると「クエスト報酬」の装備ももらえます。ガチャはありません
- **冒険者カード**：カードタブの「カードを共有」でURLを送ると、相手はログインなしでカードを見られます（内容はURLの中に入っているので、サーバーは不要です）

## 料金の仕組み（モック）
| 区分 | 料金 | 内容 |
|---|---|---|
| 無料（登録のみ） | 0円 | クイック診断、花のチャート、いちばんの伸ばしどころ、推しテーマ候補3つ、推しコミュ、イベント参加（参加費は別） |
| 詳細レポート | 1回 490円 | 伸ばしどころ3つすべて、6軸の解説、入力ごとの分析、テーマ候補9つ、講師マッチ度ランキング、成長比較 |
| 推しプラス | 月額980円 | 利用料無料、優先参加、先行通知、テーマ5つ、詳細レポートと成長比較込み |

詳細レポートは、はじめてのイベント参加（事前決済）や友達の招待でも無料で開放されます。モックでは実際の決済は行われません。

## いまの仕様と注意点
- **データは端末ごとに保存されます。** 登録内容・診断結果・写真・投票などは、使っているブラウザの中だけに保存され、ほかの人や別の端末とは共有されません
- 講師・仲間・イベントはすべて**架空のダミーデータ**です
- マイページの「データの管理」から、このブラウザのデータを初期化できます
- Publicリポジトリのため、コードは誰でも閲覧できます。パスコード `admin` も見える状態なので、本番では必ずサーバー側の権限管理に置き換えてください
