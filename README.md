# オシバナ（モック）

自分の考え方の「型」を知り、伸ばしたい方向の講師と、同じテーマを推す仲間と学び直すプラットフォームのモックです。
スマホでもPCでも動き、スマホではホーム画面に追加してアプリのように使えます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・デザイン・ダミーデータ・動作をすべて含む） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・色の設定 |
| `sw.js` | オフラインでも開けるようにする仕組み（Service Worker） |
| `icons/` | アプリのアイコン画像 |
| `README.md` | この説明書 |

ビルド（変換作業）は不要です。ファイルを置くだけで動きます。

## GitHub Pagesで公開する手順

### 1. リポジトリを作る
1. GitHubにログインし、右上の「＋」から「New repository」を選びます
2. Repository name に `oshibana` と入力します
3. 公開範囲は **Public** を選びます（無料プランでGitHub Pagesを使うにはPublicが必要です）
4. 「Create repository」を押します

### 2. ファイルをアップロードする
1. 作成したリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）を押します
2. このフォルダの中身（`index.html`、`manifest.webmanifest`、`sw.js`、`README.md`、`icons` フォルダ）をまとめてドラッグ＆ドロップします
3. 下の「Commit changes」を押します

### 3. 公開を有効にする
1. リポジトリの「Settings」→ 左メニューの「Pages」を開きます
2. 「Build and deployment」の Source で「Deploy from a branch」を選びます
3. Branch で `main`、フォルダで `/ (root)` を選び、「Save」を押します
4. 数分待つと、画面上部に公開URLが表示されます
   `https://（あなたのGitHubユーザー名）.github.io/oshibana/`

### 4. スマホのホーム画面に追加する
- **iPhone**：Safariで公開URLを開き、共有ボタン →「ホーム画面に追加」
- **Android**：Chromeで公開URLを開き、メニュー →「アプリをインストール」または「ホーム画面に追加」

## 更新のしかた
変更した `index.html` を、同じ手順（Add file → Upload files）で上書きアップロードします。
数分で公開URLに反映されます。スマホで古い画面が出る場合は、アプリを一度閉じて開き直してください。

## いまの仕様と注意点
- **データは端末ごとに保存されます。** 診断結果・写真・投票などは、使っているブラウザの中だけに保存され、ほかの人や別の端末とは共有されません
- 講師・仲間・イベントはすべて**架空のダミーデータ**です
- 右上のメニューでデモユーザーの切り替え、「講師側」ボタンで講師の画面を確認できます
- マイページ下の「デモの操作」から、保存データをリセットできます
- Publicリポジトリのため、コードは誰でも閲覧できます。個人情報や秘密の情報は入れないでください
